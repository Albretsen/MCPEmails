Why I built it
I wanted my own agents working my inbox. Every option I found wanted a copy of my mail first: sync it, index it, keep it in someone else's database for as long as the account exists. For a mailbox full of invoices, contracts and password resets, that is a lot to give up for something I only needed now and then.
So I built the version I was willing to use. Mail is fetched live when your agent asks for it and dropped once the response is sent, so there is no stored copy. The only thing kept is the mailbox credential, encrypted at rest, because the next call needs it. I run my own mail through it every day.

If I get hit by a bus
One person running an email service is a real risk. I could fall ill, lose interest, or get hit by a bus. With a closed service, that would leave your agents wired into something nobody maintains.
That is what the licence is for. MCPEmails is open source under AGPL-3.0, and the hosted service runs the same server you can clone. If I stop, you clone the repository, bring the stack up with one command, point your agent at your own instance, and carry on. The tool names stay the same. Your credentials are yours, and your mail was never stored here.
Walk the self-host path once while everything is fine, so you know it works before you need it.
