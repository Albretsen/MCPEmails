什么是邮件 MCP 服务器？
邮件 MCP 服务器（email MCP server）是 AI 助手与真实邮箱之间的桥梁。它使用 Model Context Protocol，因此 Claude、ChatGPT、Cursor 或任何其他 MCP 客户端都能通过同一个端点读取、搜索、起草和发送邮件，无需为每个应用单独做集成。
MCPEmails 就是一个托管的邮件 MCP 服务器。它支持 Gmail、Outlook 和 Microsoft 365、iCloud、Fastmail 以及任何支持 IMAP 的邮箱，同一个智能体可以同时处理多个邮箱。每次调用时，邮件都从你的服务商实时获取，从不存储在我们的服务器上。

01
范围
二十一个专注工具，覆盖日常所需。
工具覆盖日常工作：
inbox_list
、
email_read
（list、read、search）和
email_compose
（send、reply）。另有专门用于整理、删除、文件夹、草稿、定时发送、联系人、签名和无人值守自动化规则的工具。把 MCP 端点 URL 粘贴到 claude.ai、Claude Desktop、Cursor 或任何兼容 MCP 的智能体中。
02
存储
邮件实时获取，从不存储。
每一次工具调用都会实时访问你的服务商：Gmail API、Microsoft Graph 或 IMAP。邮件正文、主题和附件会发送给智能体，并随即被丢弃。我们每个收件箱只持久化一样东西，即一个加密的令牌或应用专用密码，以便进行下一次调用。例外是需要等待的外发邮件：你安排稍后发送的邮件，或等待你批准的发送，会被加密存储，其记录会保留在你的历史中。
03
发送
每一次发送都由你掌控。
每封邮件都由你自己的服务商从你的地址发出：Gmail、Outlook、Fastmail 或你自己的 SMTP 服务器。如果某个服务商拒绝来自云端地址的连接，连接会经过我们的中继。它只是一条端到端 TLS 加密的通道，因此中继永远看不到你的邮件或密码。为某个收件箱开启发送审批后，发送、回复、转发、草稿发送和定时发送都会先保留，等你在控制台审核。自动重试可以在 24 小时内重复使用同一个幂等键；只有当另一个发件地址是该收件箱已验证的 Send As 地址时，才能用它发送。
04
服务商
Gmail、Outlook、iCloud、Fastmail 及任何 IMAP 收件箱。
Gmail 通过 IMAP 使用 Google 应用密码；Outlook / Microsoft 365 使用 Microsoft 登录（OAuth 2.0；工作或学校账户可能需要其 IT 管理员先一次性批准该应用）；Fastmail、iCloud、Yahoo、Zoho 和 Yandex 使用应用专用密码；其余一切则通过通用 IMAP / SMTP 连接器。连接多个收件箱，按用途为它们打标签（work-gmail、ops-fastmail、support-imap），并将每个 API 密钥的权限范围限定到你希望该智能体访问的收件箱。团队和代理机构可以在一个共享工作区中管理所有客户的收件箱，并配有角色和审计日志。
05
访问
为智能体提供 OAuth 2.0，一键撤销。
我们采用标准 MCP（streamable-http），支持 OAuth 2.1、DCR 和 PKCE，不锁定任何厂商。可与 Claude、Cursor、VS Code、ChatGPT、Windsurf、n8n、Make、LibreChat、OpenWebUI 以及任何兼容 MCP 的客户端配合使用。OAuth 客户端通过授权码 + PKCE 自动连接；一个限定范围的 API 密钥则覆盖不支持 OAuth 的客户端和脚本化访问。你可以在仪表盘里一键撤销任何连接。
06
安全
凭据在静态时加密。
OAuth 令牌和应用密码在写入数据库前会经过 AES-256-GCM 加密。它们只在我们的服务器上、为需要它们的请求解密。加密密钥作为环境密钥存储，与数据库分离。

工作原理
你是用户。我们是管道。
从注册到你的智能体开始阅读和发送邮件，只需三步。
01
连接你的收件箱
登录并点击
连接收件箱
。选择 Gmail、Outlook、iCloud、Fastmail 或任何 IMAP 收件箱，然后完成 OAuth 或粘贴一个应用密码。凭据会被加密；你的智能体所读取的邮件从不被存储。
02
粘贴 URL：OAuth 或 API 密钥
对于支持 OAuth 2.0 的 MCP 客户端（claude.ai、Claude Desktop、Cursor 等），粘贴
https://mcpemails.com/api/mcp
，点击连接并授权。无需密钥。对于不支持 OAuth 的客户端（Cline、JetBrains、自定义脚本），改为在仪表盘里生成一个限定范围的 API 密钥。
03
你的智能体处理收件箱
智能体调用诸如
email_read()
或
email_compose()
之类的工具。MCPEmails 从你的服务商实时获取并返回结果。两次调用之间不会缓存任何内容。
inbox_list()
发现所有已连接的收件箱及其 ID。先调用此工具，无需从仪表盘复制粘贴 UUID。
email_read()
读取邮件：列出最近摘要、按 ID 获取完整邮件、批量读取至多 50 封，或运行与服务商无关的搜索，全部通过 action 参数。
email_organize()
整理邮件：移动、复制、删除、标记或归档，逐封、批量，或直接从搜索结果操作。
email_compose()
撰写：发送新邮件、在会话内回复或转发。经由 Gmail API、Microsoft Graph 或 SMTP 发出：你的域名，你的送达率。
folder()
管理文件夹（在 Gmail 上为标签）：创建、重命名或删除，并将其用作移动目标。folder_list 读取已存在的文件夹。
draft()
草稿：创建、更新并发送存储在服务商 Drafts 文件夹中的草稿。draft_list 读取已保存的草稿。
schedule()
将邮件安排在未来某个时间发送，并在发出前取消。schedule_list 显示队列中的内容。
contact_search()
通过对最近匹配邮件的实时扫描按姓名或邮箱查找联系人。不存储任何内容。

FAQ
常见问题，逐一解答
连接第一个收件箱前，你需要了解的一切。
MCPEmails 是 IMAP MCP 服务器吗？
是的。除了 Gmail 和 Outlook 之外，还有通用的 IMAP 和 SMTP 连接器，因此任何提供 IMAP 访问的邮箱都可以使用：你自己的域名、主机服务商或本地运营商的邮箱。只需填写一次服务器信息和应用密码，你的智能体就会通过 IMAP 读取邮件，并通过你自己的 SMTP 服务器发送。
一个智能体可以同时处理多个邮箱吗？
可以。把每个邮箱连接到同一个账户，你的智能体就能通过同一个端点访问全部邮箱。它可以列出已连接的收件箱，为每个请求选择合适的那一个，并在同一次对话中在客服邮箱和个人邮箱之间切换。可连接的收件箱数量取决于你的套餐。
如何在 Claude 或 ChatGPT 中添加邮件 MCP 连接器？
在客户端设置中添加自定义连接器，将 https://mcpemails.com/api/mcp 粘贴为服务器 URL，然后批准登录。支持 OAuth 的客户端无需 API 密钥。同一个 URL 也适用于 Cursor、VS Code 和其他 MCP 客户端。
你们使用分析工具吗？
我们使用保护隐私且无 Cookie 的产品分析来了解网站和设置表现。我们绝不会收集邮件内容、地址、API 密钥、OAuth 令牌或 MCP 请求数据。
它支持哪些 AI 客户端？
任何兼容 MCP 的客户端。我们是一个标准的 streamable-http MCP 服务器，支持 OAuth 2.1、DCR 和 PKCE，因此同一个收件箱可在 Claude、Cursor、VS Code、ChatGPT、Windsurf、n8n、Make、LibreChat 等中使用。粘贴一个端点 URL 即可连接，无需为每个应用重新搭建。
我可以连接哪些邮箱服务商？
通过 IMAP 和 Google 应用密码连接 Gmail 和 Google Workspace，通过 Microsoft 登录连接 Outlook 和 Microsoft 365（工作或学校账户可能需要其 IT 管理员先一次性批准该应用），通过应用专用密码连接 Fastmail、iCloud、Yahoo、Zoho 和 Yandex，以及通过通用 IMAP/SMTP 连接任何其他邮箱。想连接多少个收件箱都可以，并按用途为它们打上标签。
我的邮件会被存储在任何地方吗？
不会。你的智能体读取的邮件在每次请求时都从你的服务商实时获取，从不存储在我们的服务器上。例外是需要等待的外发邮件：你安排稍后发送的邮件，或等待你批准的发送，会被加密存储。
真的免费吗？
是的。免费版可永久连接一个收件箱，无需绑定银行卡，且你的智能体可以在其中读取、搜索、发送、回复、定时和整理。Personal 每月 $9，可在同一个智能体上接入第二个和第三个邮箱；Pro 每月 $15 最多覆盖 10 个；需要更多邮箱或其他人也需要接入时，选 Business。
AI 实际上能用我的收件箱做什么？
读取和搜索邮件，发送、回复和转发真实邮件，安排稍后发送，以及整理你的收件箱：移动、复制、标记、归档和删除。二十一个基于操作的工具，让智能体在你的收件箱内完成整件事，而不只是起草。
我该如何连接收件箱？
创建一个免费账户，连接你的邮箱（Gmail 使用 Google 应用密码，Outlook 用 Microsoft 登录，其他邮箱粘贴应用密码即可），然后将 https://mcpemails.com/api/mcp 填入你的 AI 客户端并授权。几分钟后，你的智能体就能用上这个收件箱。
我可以自托管吗？
可以。MCPEmails 采用 AGPL-3.0 开源，托管服务运行的正是你可以自己运行的同一个服务器。一个 docker-compose 栈能在约五分钟内，让完整的 MCP 服务器及其全部工具对接你自己的数据库运行，适用于任意 IMAP 或 SMTP 邮箱。Gmail 和 Outlook 登录（OAuth）以及控制台仍保留在托管套餐中。
