原则
关于邮件与智能体，
我们坚信的六件事。
这些决定塑造了产品。如果其中任何一条不再成立，那就是一个值得提交的 bug。
01
范围
十七个专注工具，覆盖日常所需。
工具覆盖日常工作：
inbox_list
、
email_read
（list、read、search）和
email_compose
（send、reply）。另有专门用于整理、删除、文件夹、草稿、定时发送、联系人、签名和无人值守自动化规则的工具。把 MCP 端点 URL 粘贴到 claude.ai、Claude Desktop、Cursor 或任何兼容 MCP 的智能体中。
02
存储
邮件实时获取，从不存储。
每一次工具调用都会实时访问你的服务商：Gmail API、Microsoft Graph 或 IMAP。邮件正文、主题和附件会发送给智能体，并随即被丢弃。我们每个收件箱只持久化一样东西，即一个加密的令牌或应用专用密码，以便进行下一次调用。唯一的例外是你安排在稍后发送的邮件：我们会保留它直到发送时间，然后为你的历史记录留存一份记录。
03
发送
发送通过你自己的服务商进行。
当你的智能体调用
email_compose
（发送或回复）时，邮件会通过 Gmail API、Microsoft Graph 或你自己的 SMTP 服务器发出。你的域名声誉和送达率完全掌握在你自己手中。我们绝不从我们自己的域名转发邮件。
04
服务商
Gmail、Outlook、iCloud、Fastmail 及任何 IMAP 收件箱。
Gmail 使用应用密码或 Google 登录（OAuth 2.0）；Outlook / Microsoft 365 使用 Microsoft 登录（OAuth 2.0；工作或学校账户可能需要其 IT 管理员先一次性批准该应用）；Fastmail、iCloud、Yahoo、Zoho 和 Yandex 使用应用专用密码；其余一切则通过通用 IMAP / SMTP 连接器。连接多个收件箱，按用途为它们打标签（work-gmail、ops-fastmail、support-imap），并将每个 API 密钥的权限范围限定到你希望该智能体访问的收件箱。团队和代理机构可以在一个共享工作区中管理所有客户的收件箱，并配有角色和审计日志。
05
访问
为智能体提供 OAuth 2.0，一键撤销。
我们采用标准 MCP（streamable-http），支持 OAuth 2.1、DCR 和 PKCE，不锁定任何厂商。可与 Claude、Cursor、VS Code、ChatGPT、Windsurf、n8n、Make、LibreChat、OpenWebUI 以及任何兼容 MCP 的客户端配合使用。OAuth 客户端通过授权码 + PKCE 自动连接；一个限定范围的 API 密钥则覆盖不支持 OAuth 的客户端和脚本化访问。你可以在仪表盘里一键撤销任何连接。
06
安全
凭据在静态时加密。
OAuth 令牌和应用密码在写入数据库前会经过 AES-256-GCM 加密。解密只在调用时于一个隔离的 Edge Function 内部进行。加密密钥作为环境密钥存储，与数据库分离。

工作原理
你是用户。我们是管道。
从注册到你的智能体开始阅读和发送邮件，只需三步。
01
连接你的收件箱
登录并点击
连接收件箱
。选择 Gmail、Outlook、iCloud、Fastmail 或任何 IMAP 收件箱，然后完成 OAuth 或粘贴一个应用密码。凭据会被加密；你的智能体所读取的邮件从不被存储。
02
粘贴 URL：OAuth 或 API 密钥
对于支持 OAuth 2.0 的 MCP 客户端（claude.ai、Claude Desktop、Cursor 等），粘贴
https://mcpemails.com/api/mcp
，点击连接并授权。无需密钥。对于不支持 OAuth 的客户端（Cline、JetBrains、自定义脚本），改为在仪表盘里生成一个限定范围的 API 密钥。
03
你的智能体处理收件箱
智能体调用诸如
email_read()
或
email_compose()
之类的工具。MCPEmails 从你的服务商实时获取并返回结果。两次调用之间不会缓存任何内容。
inbox_list()
发现所有已连接的收件箱及其 ID。先调用此工具，无需从仪表盘复制粘贴 UUID。
email_read()
读取邮件：列出最近摘要、按 ID 获取完整邮件、批量读取至多 50 封，或运行与服务商无关的搜索，全部通过 action 参数。
email_organize()
整理邮件：移动、复制、删除、标记或归档，逐封、批量，或直接从搜索结果操作。
email_compose()
撰写：发送新邮件、在会话内回复或转发。经由 Gmail API、Microsoft Graph 或 SMTP 发出：你的域名，你的送达率。
folder()
管理文件夹（在 Gmail 上为标签）：创建、重命名或删除，并将其用作移动目标。folder_list 读取已存在的文件夹。
draft()
草稿：创建、更新并发送存储在服务商 Drafts 文件夹中的草稿。draft_list 读取已保存的草稿。
schedule()
将邮件安排在未来某个时间发送，并在发出前取消。schedule_list 显示队列中的内容。
contact_search()
通过对最近匹配邮件的实时扫描按姓名或邮箱查找联系人。不存储任何内容。
