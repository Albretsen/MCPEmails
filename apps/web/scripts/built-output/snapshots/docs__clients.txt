MCP clients
Connect your inbox to any MCP client
One hosted MCP server, 14 setup guides. Pick the client you actually use and follow the steps written for it, not a generic template.
MCPEmails is a hosted MCP server for email. You connect a mailbox once, then paste one URL into the client you already work in. 10 of the 14 clients here run the OAuth browser flow and need no API key at all; the rest take a scoped API key in an Authorization header.
